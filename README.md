# EnduranceHub Tracker

Система мониторинга и анализа эндьюранс-гонок для Assetto Corsa Competizione в реальном времени.

## 🎯 Возможности

- **Real-time мониторинг сессии** — отслеживание позиций, времени кругов, отставаний от лидера
- **Управление стинтами** — автоматическое определение смены пилота, история отрезков, ручное составление плана стинтов и правка пилота/времени
- **Телеметрия** — запись работы с педалями и рулём в реальном времени
- **Карта трассы** — визуализация позиций всех машин на треке (генерируется автоматически)
- **Сетапы** — просмотр и анализ настроек автомобиля
- **Встроенный Server и Agent** 🆕 — запуск и управление всеми компонентами из одного окна с логами в реальном времени
- **Кросс-платформенность** — Windows, Linux, macOS
- **Автообновления** — через Velopack (только для установленных версий)
- **Мастер установки** — MSI с выбором «только для меня» / «для всех пользователей»
- **Интерактивное обучение** — при первом запуске подсвечивает элементы интерфейса и объясняет их
- **Контрольные суммы** — `SHA256SUMS.txt` в каждом релизе для проверки скачанного файла

## 🏗️ Архитектура

Проект состоит из нескольких компонентов:

### EnduranceHub.Server
ASP.NET Core сервер с REST API и SignalR хабом. Подключается к ACC Broadcasting API, обрабатывает телеметрию и хранит данные в PostgreSQL.

**Порт по умолчанию:** `5261`

### EnduranceHub.Client
Десктопное приложение (Avalonia UI) для визуализации данных. Подключается к серверу через SignalR для получения обновлений в реальном времени.

### EnduranceHub.Broadcaster
Консольная утилита для отладки и мониторинга ACC Broadcasting протокола. Показывает все события от игры в терминале.

### EnduranceHub.Agent
Агент для чтения телеметрии с устройств ввода (руль, педали) из Shared Memory ACC и отправки на сервер.

## 🚀 Быстрый старт (новый способ!)

> **🆕 Теперь всё управляется из одного окна!** Не нужно запускать отдельные exe файлы.

### 1. Скачайте и установите

Скачайте последний релиз из [Releases](https://github.com/Ilya22865/acc-endurance-tracker/releases):

| Платформа | Файл | Примечание |
|-----------|------|------------|
| Windows (мастер установки) | `EnduranceHub-win-win.msi` | Рекомендуется: выбор «для всех пользователей» или «только для меня» |
| Windows (быстрая установка) | `EnduranceHub-win-win-Setup.exe` | Установка в один клик, без вопросов |
| Linux | `EnduranceHub-linux.AppImage` | Перед запуском: `chmod +x` |
| macOS | `EnduranceHub-osx-osx-Setup.pkg` | Apple Silicon |

**Куда ставится программа (Windows, MSI).** В мастере установки есть шаг с выбором области установки:

- **Только для меня** — `%LOCALAPPDATA%\EnduranceHub-win\current`, права администратора не нужны;
- **Для всех пользователей** — `C:\Program Files\EnduranceHub\current`, нужны права администратора.

MSI — это обычный установщик Windows: он появляется в «Установка и удаление программ», корректно удаляется и обновляется. Папку установки можно изменить и вручную из командной строки:

```powershell
msiexec /i EnduranceHub-win-win.msi VELOPACK_INSTALLDIR="D:\Apps\EnduranceHub"
```

Пользовательские данные (настройки, логи, `server.appsettings.json`) хранятся отдельно, в `%LOCALAPPDATA%\EnduranceHub`, и не удаляются при обновлении или смене папки установки.

### 1.1. Первый запуск: интерактивное обучение

После установки при первом запуске EnduranceHub показывает тур по интерфейсу: экран затемняется, нужная кнопка или вкладка подсвечивается оранжевой рамкой, а рядом появляется карточка с объяснением. Шаги охватывают все вкладки (Позиции, Стинты, Телеметрия, Радар, Сетап, Карта, Сервер, Агент, Настройки) и поле подключения к серверу.

- **Далее / Назад** или стрелки `←` `→` — переключение шагов;
- `Esc` или «Пропустить» — закрыть тур;
- тур показывается один раз, флаг хранится в `%LOCALAPPDATA%\EnduranceHub\settings.json`;
- запустить заново: **Настройки → Обучение → «Пройти обучение заново»**.

### 1.2. SmartScreen и «Неизвестный издатель»

Windows показывает предупреждение SmartScreen для любого нового установщика без узнаваемой цифровой подписи — это репутация файла, а не вирус. Файлы EnduranceHub проверяются в Windows Defender и не содержат обнаружений, но до покупки сертификата подписи кода предупреждение может появляться. Что делать:

1. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
2. Сверьте файл с контрольными суммами из релиза (`SHA256SUMS.txt`):

```powershell
Get-FileHash .\EnduranceHub-win-win.msi -Algorithm SHA256
# сравните вывод со строкой для этого файла в SHA256SUMS.txt
```

3. Скачивайте только со страницы GitHub Releases этого репозитория.

После подключения подписи кода (Azure Trusted Signing / SignPath для open-source) издатель будет отображаться как проверенный, а предупреждение исчезнет. Подробности для мейнтейнеров — в [RELEASING.md](RELEASING.md).

### 2. Настройте базу данных

Запустите PostgreSQL через Docker Compose:

```bash
docker-compose up -d
```

Или установите PostgreSQL локально и создайте базу `endurancehub`.

### 3. Настройте сервер

Если вы будете запускать ACC (хост сервера), отредактируйте `server.appsettings.json` в папке пользовательских данных:

Обычно находится в:
```
%LOCALAPPDATA%\EnduranceHub\server.appsettings.json
```

Файл создаётся автоматически при первом запуске сервера (из настроек по умолчанию). Он хранится вне папки установки, поэтому не пропадает при обновлениях.

Server и Agent устанавливаются вместе с клиентом, поэтому отдельно скачивать их не нужно.

Содержимое:

```json
{
  "ConnectionStrings": {
    "EnduranceHub": "Host=localhost;Port=5432;Database=endurancehub;Username=postgres;Password=postgres"
  },
  "Acc": {
    "Ip": "192.168.1.100",              // IP машины с запущенным ACC
    "Port": 9000,                        // Broadcasting порт ACC (по умолчанию 9000)
    "DisplayName": "EnduranceHubServer",
    "Password": "",                      // Пароль из broadcasting.json ACC (если установлен)
    "CommandPassword": "",
    "UpdateIntervalMs": 100,
    "OurCarRaceNumber": 777              // ВАЖНО: укажите номер ВАШЕЙ машины!
  }
}
```

**⚠️ Критически важно:** Установите `OurCarRaceNumber` — номер вашей машины в гонке. Без этого система будет автоматически выбирать первую машину с 3+ пилотами, что может привести к ошибочному отслеживанию.

### 4. Настройка ACC Broadcasting

В папке ACC (обычно `Documents\Assetto Corsa Competizione\Config`) создайте или отредактируйте файл `broadcasting.json`:

```json
{
  "updListenerPort": 9000,
  "connectionPassword": "",
  "commandPassword": ""
}
```

Запустите ACC и загрузите любую сессию — Broadcasting API будет активен.

### 5. Запуск — ВСЁ ИЗ ОДНОГО ОКНА! 🎉

#### Если вы запускаете ACC (хост сервера):

1. Запустите **EnduranceHub** (ярлык на рабочем столе или в меню «Пуск»)
2. Перейдите на вкладку **«Сервер»**
3. Нажмите **«Запустить»** — сервер запустится, логи появятся ниже
4. Перейдите на вкладку **«Позиции»** и используйте приложение

#### Если вы подключаетесь к чужому серверу:

1. Запустите **EnduranceHub**
2. Укажите URL сервера в поле подключения (например, `http://10.0.0.5:5261` через Radmin VPN)
3. Нажмите **«Подключить»**
4. Готово! Сервер НЕ запускается на вашей машине

#### Для записи телеметрии педалей/руля:

1. Перейдите на вкладку **«Агент»**
2. Выберите себя в списке **«Я за рулём как»** (это задаёт ваш DriverIndex)
3. Нажмите **«Запустить»**

Агент запускается **только на ПК того, кто сейчас ведёт машину**. При смене пилота старый пилот останавливает Агента, новый выбирает себя в списке и запускает Агента у себя — сервер сам закроет старый стинт и откроет новый.

Подробная инструкция: [EMBEDDED_SERVICES.md](EMBEDDED_SERVICES.md)

## 🌐 Работа через Radmin VPN

Для командных эндьюранс-гонок:

1. **Все участники** подключаются к одной сети Radmin VPN
2. **Один пилот** (у кого запущена игра) запускает **Server** на своей машине
3. **Остальные пилоты** подключают свои **Client** к IP сервера в Radmin сети (например, `10.0.0.5:5261`)
4. **Только пилот, который сейчас за рулём**, запускает **Agent** на своём компьютере для записи телеметрии педалей/руля. При смене пилота старый останавливает Agent, новый запускает у себя.

### Определение IP в Radmin VPN
```bash
# Windows
ipconfig | findstr "Radmin"

# Linux/macOS
ip addr | grep radmin
```

### Если для Discord или сайтов включён ещё один VPN

EnduranceHub ходит к серверу **напрямую, минуя системный прокси**: VPN-клиенты
(Hiddify, v2rayN, Nekoray, Clash и похожие) при включении прописывают системный
прокси, из-за которого новые соединения с сервером в Radmin/ZeroTier рвутся.
Поэтому включать и выключать VPN для Discord не нужно — клиент и агент
продолжают работать и с включённым VPN.

Если VPN работает в режиме **TUN** (перехватывает весь трафик) и забирает маршрут
до Radmin-сети, добавьте Radmin-подсеть в исключения VPN (split tunneling) или
пропишите маршрут до сервера напрямую. В этом случае клиент покажет «сеть
недоступна» или «таймаут», а в `agent.log` будет точная сетевая ошибка.

## 📊 Как это работает

### Определение "нашей" машины

Система определяет вашу машину двумя способами:

1. **По номеру** (рекомендуется) — через `Acc:OurCarRaceNumber` в `server.appsettings.json`
2. **Автоматически** — первая машина с ≥3 пилотами (может быть неточно в больших гонках)

### Стинты

Система автоматически:
- Открывает новый стинт при смене пилота (по `DriverIndex` из Broadcasting)
- Закрывает предыдущий стинт
- Сохраняет все стинты в БД

Вы можете поправить пилота и время начала/конца каждого стинта в полях над таблицей — это удобно для планирования отрезков.

### Телеметрия педалей/руля

**Agent** читает Shared Memory ACC и отправляет данные о работе с педалями газа/тормоза и углом руля. Эти данные отображаются в клиенте в виде графиков в реальном времени (вкладка с телеметрией).

### Карта трассы

При первом чистом круге система записывает контур трассы по координатам машины и строит живую карту с позициями всех участников.

## 🛠️ Тестирование

### 1. Тестирование Broadcasting подключения

```bash
cd src/EnduranceHub.Broadcaster
dotnet run -- 192.168.1.100 9000

# Для локального тестирования с мок-данными:
dotnet run -- --mock
```

Вы увидите события от ACC в терминале: список машин, обновления позиций, круги и т.д.

### 2. Тестирование телеметрии Agent

```bash
cd src/EnduranceHub.Agent
dotnet run -- --server http://localhost:5261
```

Agent читает Shared Memory ACC, поэтому для проверки запустите игру.

### 3. Тестирование определения "нашей" машины

1. Установите правильный `OurCarRaceNumber` в `server.appsettings.json`
2. Запустите сервер и клиент
3. В клиенте на вкладке "Позиции" ваша машина должна подсвечиваться **зелёной рамкой слева**
4. Проверьте, что стинты открываются только для вашей машины (вкладка "Стинты")

### 4. Тестирование автообновлений

Для тестирования автообновлений нужно:

1. **Создать релиз:**
   ```bash
   git tag v1.0.0-beta.2
   git push origin v1.0.0-beta.2
   ```

2. **GitHub Actions** соберёт и опубликует релиз с установочными файлами и `SHA256SUMS.txt`

3. **Установить приложение** из релиза:
   - Windows (мастер, выбор области установки): `EnduranceHub-win-win.msi`
   - Windows (в один клик): `EnduranceHub-win-win-Setup.exe`
   - Linux: `EnduranceHub-linux.AppImage`
   - macOS: `EnduranceHub-osx-osx-Setup.pkg`

4. **Создать новый релиз** с увеличенной версией (например, `v1.0.0-beta.3`)

5. **Запустить установленное приложение** — оно автоматически скачает и применит обновление при следующем запуске

Автопроверка при старте и кнопки «Проверить обновления» / «Установить» в настройках используют один и тот же сервис обновлений, поэтому фоновая загрузка и ручная установка не конфликтуют. Если операция уже идёт, приложение покажет «Проверка или установка обновления уже выполняется» вместо ошибки блокировки.

**⚠️ Важно:** Автообновления работают только для приложений, установленных через Velopack установщики. Запуск через `dotnet run` или из папки publish не поддерживает автообновления.

## 🐛 Отладка

### Сервер не видит ACC
- Проверьте, что ACC запущен и Broadcasting включён
- Проверьте IP и порт в `server.appsettings.json`
- Проверьте, что нет блокировки файрволом (порт 9000 UDP)

### Клиент не подключается
- Проверьте, что сервер запущен
- Проверьте URL сервера в клиенте
- Для Radmin VPN: используйте IP из Radmin сети, не `localhost`
- Если включён VPN для Discord: приложение ходит напрямую, минуя системный прокси.
  При TUN-режиме добавьте Radmin-подсеть в исключения VPN (split tunneling)

### Стинты не открываются
- **Критично:** Проверьте `OurCarRaceNumber` в `server.appsettings.json`
- Убедитесь, что номер машины в игре совпадает с настройкой
- Проверьте логи сервера на предупреждения об определении машины

### Agent не отправляет телеметрию
- Убедитесь, что ACC запущен (для Shared Memory)
- Проверьте, что Agent зарегистрирован (сообщение "OK" при запуске)
- Проверьте, что выбранный `DriverIndex` соответствует текущему пилоту в игре
- В `%LOCALAPPDATA%\EnduranceHub\logs\agent.log` ищите строки `[net]`
  (потеря/восстановление связи) и `[warn]` с точной сетевой ошибкой.
  Агент сам копит телеметрию при обрыве и досылает её после восстановления

### Логи сервера

Логи сохраняются в:
- Windows: `%LOCALAPPDATA%\EnduranceHub\logs\server.log`
- Linux/macOS: `~/.local/share/EnduranceHub/logs/server.log`
