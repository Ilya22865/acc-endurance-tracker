# 🚀 Встроенный Server и Agent — новая функция!

Теперь вам **не нужно запускать отдельные exe файлы** — всё управляется прямо из клиентского приложения!

## ✨ Что нового?

### Две новые вкладки:

1. **🖥️ Сервер** — запуск и управление EnduranceHub.Server прямо из клиента
2. **🎮 Агент** — запуск и управление Agent для телеметрии педалей/руля

## 📋 Как использовать

### Вариант 1: Вы запускаете ACC (хост сервера)

1. Запустите **EnduranceHub.exe** (установленный клиент)
2. Перейдите на вкладку **"Сервер"** (фиолетовая иконка "SV")
3. Путь к `EnduranceHub.Server.exe` фиксирован — ничего указывать не нужно
4. Нажмите **"▶ Запустить"**
5. В окне с логами увидите:
   ```
   [12:30:45] 🚀 Запуск сервера: C:\Users\...\AppData\Local\EnduranceHub-win\current\Server\EnduranceHub.Server.exe
   [12:30:46] ✅ Сервер запущен
   [12:30:46] info: Connecting to ACC at 127.0.0.1:9000...
   [12:30:47] info: ACC connection: Connected
   ```
6. Перейдите на вкладку **"Позиции"** и используйте приложение как обычно

**Для остановки:** Нажмите **"⏹ Остановить"** на вкладке Сервер

### Вариант 2: Подключение к чужому серверу (Radmin VPN)

1. Запустите **EnduranceHub.exe**
2. На главном экране укажите URL сервера: `http://10.0.0.5:5261` (IP из Radmin VPN)
3. Нажмите **"Подключить"**
4. Готово! Сервер **не запускается**, вы просто смотрите данные

### Вариант 3: Запуск Agent для своей телеметрии

1. На вкладке **"Агент"** (розовая иконка "AG")
2. Выберите себя в списке **"Я за рулём как"** (0, 1, 2 и т.д. — ваш номер в списке пилотов команды)
3. Нажмите **"▶ Запустить"**
4. В логах увидите:
   ```
   [12:35:20] 🚀 Запуск Agent: DriverIndex=0, Server=http://localhost:5261
   [12:35:21] ✅ Agent запущен
   [12:35:21] Регистрирую пилота (DriverIndex=0)... OK
   [12:35:21] Агент работает. Ctrl+C для выхода.
   ```

## 🎯 Преимущества

✅ **Всё в одном окне** — не нужно держать открытыми несколько терминалов  
✅ **Логи в реальном времени** — видно всё, что происходит  
✅ **Фиксированные пути** — Server и Agent устанавливаются вместе с клиентом, путь указывать не нужно  
✅ **Простая остановка** — одна кнопка  
✅ **Не нагружает систему** — если не запустили Server/Agent, они не работают

## 📁 Где находятся Server и Agent?

Установщик Velopack кладёт клиент, Server и Agent в одну папку приложения:

```
%LOCALAPPDATA%\EnduranceHub-win\current\
├── EnduranceHub.Client.exe
├── Server\
│   ├── EnduranceHub.Server.exe
│   └── appsettings.json        (настройки по умолчанию)
└── Agent\
    └── EnduranceHub.Agent.exe
```

Клиент всегда запускает их по этим фиксированным путям:
- `%LOCALAPPDATA%\EnduranceHub-win\current\Server\EnduranceHub.Server.exe`
- `%LOCALAPPDATA%\EnduranceHub-win\current\Agent\EnduranceHub.Agent.exe`

При обновлении через Velopack папка `current` заменяется целиком, поэтому Server и Agent обновляются вместе с клиентом. Пользовательские настройки сервера при этом не теряются — они хранятся отдельно:

```
%LOCALAPPDATA%\EnduranceHub\server.appsettings.json
```

Файл создаётся автоматически при первом запуске сервера.

## 🛠️ Настройка для командной гонки

### Машина с ACC (хост):
1. Запустить PostgreSQL (Docker или локально)
2. В клиенте: вкладка "Сервер" → "Запустить"
3. Узнать свой IP в Radmin: `ipconfig | findstr "Radmin"`
4. Сообщить команде IP, например: `10.0.0.5`

### Остальные пилоты:
1. URL сервера: `http://10.0.0.5:5261`
2. "Подключить"
3. Вкладка "Агент" → выбрать себя в списке → "Запустить" (только когда вы за рулём)

### Смена пилота в эндьюранс-гонке:
1. Пилот, который заканчивает стинт, нажимает **"Остановить"** на вкладке "Агент".
2. Новый пилот выбирает себя в списке **"Я за рулём как"** и нажимает **"Запустить"**.
3. Сервер автоматически закроет старый стинт и откроет новый по смене `DriverIndex` из ACC.
4. Держать два Агента одновременно не нужно: пакеты неактивного пилота сервер игнорирует, но лишний Агент только мешает и шлёт трафик.

## 🐛 Если что-то не работает

**Сервер не запускается:**
- Убедитесь, что приложение установлено через Setup (тогда Server лежит внутри папки приложения)
- Проверьте, что PostgreSQL запущен
- Посмотрите логи на вкладке Сервер — там будет ошибка

**Agent не отправляет данные:**
- Убедитесь, что ACC запущен (Agent читает Shared Memory игры)
- Проверьте DriverIndex — должен соответствовать вашему номеру в команде
- Убедитесь, что сервер запущен и доступен

**Логи пустые:**
- Подождите 1-2 секунды после запуска
- Если всё равно пусто — возможно, повреждена установка: переустановите приложение из Setup

## 🎮 Теперь запуск выглядит так:

**Раньше:**
```cmd
# Терминал 1
docker-compose up -d

# Терминал 2
cd Server
EnduranceHub.Server.exe

# Терминал 3
cd Agent
EnduranceHub.Agent.exe --server http://localhost:5261 --driver-index 0

# Терминал 4
EnduranceHub.Client.exe
```

**Теперь:**
1. Двойной клик `EnduranceHub.exe`
2. Вкладка "Сервер" → Запустить
3. Вкладка "Агент" → Указать DriverIndex → Запустить
4. Готово! 🏁

---

**Примечание:** Если вы НЕ запускаете Server/Agent через вкладки, они не будут работать и не будут нагружать систему. Это идеально для зрителей, которые только смотрят данные с сервера команды.
